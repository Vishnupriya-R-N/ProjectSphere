# ProjectSphere

ProjectSphere is a web-based project management system for managing student teams, projects, guides, and project progress.

## Technologies

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Current Features

- User registration and login
- JWT-based authentication
- Team creation and management
- Project creation
- Project listing
- Team-project relationship

## Project Status

Currently under development.
